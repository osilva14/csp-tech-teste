# 📦 csp-tech-teste

Este repositório contém a solução do teste técnico para a CSP Tech, utilizando automação de testes com Cypress. O objetivo é validar funcionalidades de uma aplicação web através de testes end-to-end, seguindo boas práticas de desenvolvimento e organização do código.

---

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como parte de um processo seletivo e tem como foco principal demonstrar habilidades em:

- Escrita de testes automatizados com Cypress
- Organização dos testes seguindo boas práticas.
- Validação de cenários de criação, visualização, edição e exclusão.

---

## 🚀 Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)
- [Cypress](https://www.cypress.io/)
- [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [Visual Studio Code](https://code.visualstudio.com/) (recomendado)
